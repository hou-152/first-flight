# Linka · PRD · v1-launch

> 文件位置：`iterations/v1-launch/PRD.md`
> 配合项目根的 BRIEF.md 阅读。这份 PRD 描述首版上线时要做的事。

## 1. 项目背景
独立设计师 Linka 的个人作品集网站，向潜在客户和招聘方展示她的品牌设计与插画作品。

参见：[BRIEF.md](../../BRIEF.md)

## 2. 本次目标
让陌生访客在打开首页 60 秒内确认 Linka 的设计风格 / 定位 / 可合作性，并能通过表单留下合作咨询。第一版聚焦"作品展示 + 信任建立 + 联系入口"。

## 3. 用户与关键场景

### 场景 1：品牌创始人的初次评估
- **用户**：中小品牌创始人，通过同行推荐听说 Linka，正在挑外包设计师
- **旅程**：进首页 → 看一句话定位 → 浏览首页精选作品 → 点击 1-2 个作品详情看设计思路 → 进入联系页填表单
- **结果**：留下项目类型 / 预算 / 联系方式，邮件通知到 Linka

### 场景 2：Design Lead 的候选人筛选
- **用户**：公司内部 design lead，在评估自由设计师候选人
- **旅程**：进首页 → 跳到作品列表 → 按"品牌设计 / 插画"筛选 → 快速扫 8-10 件作品 → 点 2-3 件看设计思路 → 复制 Linka 邮箱到内部群
- **结果**：把 Linka 加入候选人名单

### 场景 3：Linka 自己作为名片用
- **用户**：Linka 在和潜在客户初次接触，对方问"能看下你之前的作品吗"
- **旅程**：Linka 把首页链接发过去 → 对方打开 → 60 秒内确认风格匹配度
- **结果**：对方愿意进一步聊

## 4. 页面结构

- `/` —— 首页：一句话定位 + 精选作品 + 联系入口
- `/works` —— 作品列表：全部作品，支持类型筛选
- `/works/[slug]` —— 作品详情：单件作品的图集 + 设计思路
- `/about` —— 关于：Linka 的背景介绍 + 合作品牌 + 风格自述
- `/contact` —— 联系：合作咨询表单

## 5. 信息架构

### 首页 `/`
- **Hero 区** —— 第一屏抓住注意，传达定位
  - 内容槽：一句话定位(15-25 字) / Linka 头像或主视觉 / 主 CTA（"看全部作品"或"咨询合作"）
- **精选作品区** —— 展示 6-8 件代表作
  - 内容槽：6-8 张作品封面图 / 每张配一行标题 + 类型标签 / "查看更多"链接到 `/works`
- **简介区** —— 一段话自我介绍，建立信任
  - 内容槽：Linka 一段话介绍(80-120 字) / 合作过的 3-5 个品牌 logo
- **CTA 区** —— 引导联系
  - 内容槽：一句话引导文案 / "开始合作"按钮跳 `/contact`

### 作品列表 `/works`
- **筛选区** —— 按类型筛选作品
  - 内容槽：类型标签清单（品牌设计 / 插画 / 其他）
- **作品网格区** —— 全部作品瀑布流
  - 内容槽：每件作品的封面图 + 标题 + 类型 + 完成年份

### 作品详情 `/works/[slug]`
- **作品头部** —— 作品基本信息
  - 内容槽：标题 / 客户名 / 完成时间 / 类型标签
- **图集区** —— 作品视觉展示
  - 内容槽：3-6 张作品图（含 hero + 细节）
- **设计思路区** —— 500-800 字设计说明
  - 内容槽：背景 / 挑战 / 思路 / 结果 四段文字
- **导航区** —— 上一件 / 下一件
  - 内容槽：上一件作品链接 + 缩略图 / 下一件作品链接 + 缩略图

### 关于 `/about`
- **个人介绍区** —— 详细自我介绍
  - 内容槽：Linka 头像 / 身份一句话 / 详细介绍(300-500 字) / 教育和经历时间线
- **合作品牌区** —— 信任背书
  - 内容槽：合作品牌 logo 列表（8-12 个）
- **联系入口** —— 直接跳联系
  - 内容槽：一句话 / 按钮跳 `/contact`

### 联系 `/contact`
- **表单区** —— 合作咨询
  - 内容槽：表单字段（姓名 / 邮箱 / 项目类型 / 预算区间 / 描述）/ 提交按钮 / 提交成功提示
- **直接联系区** —— 备选联系方式
  - 内容槽：邮箱地址 / 社交账号链接

## 6. 目标衡量

**主指标（上线后 90 天）：**
- 通过联系表单收到 ≥ 5 份认真合作咨询（不含群发广告）
- 平均访客停留时长 ≥ 90 秒

**漏斗指标（过程指标）：**
- 到达首页 → 月访客 ≥ 200
- 浏览作品 → 进入作品列表或作品详情的比例 ≥ 40%
- 动作 → 点击进入 `/contact` 的访客 ≥ 5%
- 转化 → 提交联系表单的比例 ≥ 1.5%

## 7. 范围
**这一版会做：** 5 个核心页面（首页 / 作品列表 / 作品详情 / 关于 / 联系）、作品类型筛选、联系表单 + 邮件通知、基础 SEO（meta + sitemap + OG image）

**这一版不做：** 博客 / 文章系统、客户管理后台、付费下载素材、用户登录注册、多语言、评论 / 互动、社交分享按钮、订阅 newsletter、移动 App
